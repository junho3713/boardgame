# 관동 카드 리그 · 육성 듀얼 (시험판)

1세대 포켓몬을 테마로 만든 비공식 팬 게임입니다. 공유 카드 드래프트, 세 마리 육성·진화, 자동 태그 배틀과 배틀당 한 번의 플레이어 개입으로 구성합니다. 먼저 배틀 3승을 달성하면 승리합니다.

사용자가 제안한 구조에 따라 7 Wonders Duel의 공유 카드 선택·해제 방식과 Tag Team의 순서를 유지하며 카드를 삽입하는 자동 전투 구조를 참고했습니다. 승리 조건, 포켓몬 성장·능력치·상성·개입 수치는 이 시제품의 테스트 규칙입니다. 원작 룰북의 문장·카드·그래픽을 복제하지 않았습니다.

구조 참고:
- https://www.rprod.com/en/games/7-wonders-duel
- https://www.scorpionmasque.com/en/tag-team

포켓몬 이름과 그림의 권리는 Nintendo / Creatures / GAME FREAK에 있습니다. 포켓몬 그림은 PokéAPI sprites의 official-artwork PNG 및 대체 스프라이트를 불러옵니다.
- https://github.com/PokeAPI/sprites

컴퓨터 연습은 브라우저에서 실행·저장합니다. 친구 1대1은 방 코드와 임시 세션으로 서버에 연결하며, 재시작 시 방이 종료될 수 있습니다. 공개 온라인 게임 목록에는 시험 기간 동안 표시하지 않습니다.
