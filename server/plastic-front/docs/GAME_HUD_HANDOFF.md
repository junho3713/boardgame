# 게임 내부 HUD (2026-11-11)

## 배치

- `battle-hud.js`는 기존 DOM 노드를 이동합니다. 게임 상태와 기존 버튼 ID·이벤트는 유지합니다.
- 체력·시간과 명령 도구 모음은 `battleFrame` 내부에 배치합니다. 게임 창은 브라우저의 표시 영역을 채웁니다.
- 분대·강화 창에 기존 사이드바와 작전 능력·진화·자동충원 버튼을 모읍니다. 상대 정보는 하단의 기존 버튼으로 엽니다.
- 메뉴에는 영구 강화·소리·도움말·새 작전·전체화면과 조작 안내를 모읍니다. 설정·일시정지는 전장에 남깁니다.
- 보급 도구는 페이지가 아닌 전장에 고정합니다. 모바일과 전체화면에도 같은 구성입니다.

## 상태와 접근성

- `game.js`의 기존 `openModal`/`closeModal`로 패널을 열고 닫습니다. 싱글 전투 중 열면 일시정지하고 닫으면 이전 상태로 돌아갑니다.
- 하위 메뉴를 열기 전에 원래 패널을 닫아 재개 상태를 보존합니다. 새로 추가되는 자동충원 버튼도 캡처 단계에서 같은 처리를 합니다.
- 새 패널은 `ui-shell.js`보다 먼저 생성되어 기존 대화상자 포커스 제어와 Tab 이동에 포함됩니다. Escape와 새 작전·저장 복원 시에도 닫힙니다.
- 기존 canvas의 크기·투영·입력 좌표 계산은 변경하지 않습니다.

## 검증

- 기존 게임·협동·서버 회귀 테스트 373개 통과.
- 실제 HTML과 HUD 모듈의 DOM 실행으로 기존 ID/노드 보존, 중복 ID 없음, 패널·버튼 위치, 일시정지·재개, 하위 도움말 전환, 준비·종료 상태, 전체화면 버튼 연결을 확인했습니다.
- 브라우저/CUA와 Windows 화면 도구가 `failed to write kernel assets` 오류로 실행되지 않아 실제 렌더링과 터치 화면의 시각 검증은 수행하지 못했습니다.

## 반영 파일

- 웹 루트: `battle-hud.js`, `battle-hud.css`, `game.js`, `index.html`, `patch-notes.html`, `patch-notes.txt`.
- 이 문서는 서버 정적 파일로 업로드하지 않습니다.
- 새 계정에서는 기존 Sites 프로젝트의 소스 쓰기 자격 증명이 `Sites project not found`로 거절되었습니다. 원래 프로젝트에 편집 권한이 있는 계정에서 같은 정적 파일을 반영해야 합니다. Sites 전용 index의 협동 Render 링크·리다이렉트는 보존해야 합니다.
