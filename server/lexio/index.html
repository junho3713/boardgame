렉시오

같은 개수, 더 강한 조합.

타일을 먼저 털고 점수칩을 모아 보세요. 2가 가장 강해요.
3~5명이 함께하거나, 빈자리에 컴퓨터를 넣어 플레이해요.

컴퓨터와 먼저 플레이하기

무료 서버는 첫 접속 때 잠시 기다릴 수 있어요. 서버가 재시작되면 방이 종료되고, 방은 최대 2시간 유지돼요.

함께 앉을 사람들을 기다려요.

방 코드

    각자 64점으로 시작하고 5라운드를 정산해요. 3인: 1~9 / 4인: 1~13 / 5인: 1~15 타일을 사용해요.

    방장이 시작하면 같은 게임판으로 이동해요.
