## 토끼 태엽 북 토이 외형·동작 교체 (2026-11-09)

- 음표를 토끼 옆으로 옮겨 얼굴과 귀가 보이도록 했습니다. 파손되면 기울어진 모습과 수리 시간을 표시하고, 수리 뒤 다시 북을 칩니다.
- 희귀 보급에서 25% 확률로 합류하며 별도 2슬롯을 사용합니다. 반경 300 아군 이동속도 +5%·일반 공격속도 +3%, 중복 획득 시 완전 수리, 파손 시 20초 뒤 체력 50% 수리를 적용합니다.

## 지휘관 궁극기 검기·화염·명중 연출 (2026-11-09)

- 시온의 홍련 회전베기는 몸 주위로 검붉은 초승달 모양의 검기가 돌아갑니다. 밝은 칼날 뒤로 비치는 잔상이 따라오고, 베인 적 위치에 짧은 섬광과 불티가 남습니다.
- 화염방사 대장과 화린의 지옥불 분사는 총구에서 가느다랗게 시작해 끝으로 갈수록 넓어집니다. 밝은 중심 불길과 주황색 바깥 불길이 서로 다른 속도로 일렁이고, 맞은 적에게 불꽃이 튑니다.
- 기본 대장과 시노의 쌍권총 난사에서는 양쪽 총구에서 번갈아 섬광이 터집니다. 밝은 탄두와 꼬리 궤적이 피격 위치까지 날아가고, 도착한 자리에 불티가 튑니다. 장갑 표적에는 불티가 더 많이 퍼집니다.
- 명중 효과는 실제로 체력이 줄어든 위치를 기준으로 표시합니다. 막힌 공격에는 명중 효과가 뜨지 않고, 적을 처치한 마지막 공격에도 효과가 보입니다. 일반 전투와 보스 연습에 함께 적용했습니다.

## 희귀 보급 서포토이 · 보스킬러 대기 연출 (2026-11-09)

- 태엽 북 토이: 반경 300의 아군 이동속도 +5%, 일반 공격속도 +3%. 중첩되지 않으며 의무병의 1초 치료와 레토나의 4초 추첨 간격은 유지합니다.
- 미끼 토이: 12초마다 최대 3초 지속하는 미끼를 놓아 일반 적 최대 2명을 유도합니다. 보스와 이미 발사된 공격은 유도하지 않습니다.
- 물대포 거북이: 5초마다 전방 최대 3명을 밀어냅니다. 곤충형 보스는 짧게 밀지만 인간형·차량·사검의 군주 보스는 밀지 않습니다. 전투 이동속도는 90으로 느리며 비전투 중 크게 뒤처지면 따라잡습니다.
- 전기 토이: 10초마다 위협적인 일반 적 1명을 1초 기절시킵니다. 보스는 기절하지 않습니다. 기본 체력이 낮아 엄호가 필요합니다. 밀림·기절 후 같은 적에게 3초 제어 저항을 적용합니다.
- 별도 2슬롯을 사용해 일반 병력 한도를 차지하지 않습니다. 중복은 기존 토이를 완전 수리하고, 2슬롯이 찼을 때는 교체 또는 현재 편성 유지를 선택합니다. 파손 시 전사·회수 보상 없이 20초 후 체력 50%로 수리됩니다. 자동 시전이며 추가 조작 버튼은 없습니다.
- 네 종류를 서로 다른 광택 플라스틱·태엽 모델로 제작했습니다. 8방향 이동, 정지 시 발 정렬, 북의 음표·미끼의 스프링·거북이 물줄기와 물방울·전기와 기절 표시를 적용했습니다. 발사 중 포구 방향은 이동 방향과 별도로 유지합니다. 이미지 다운로드를 추가하지 않습니다.
- 보스킬러는 당첨 후 움직이는 레토나 위에서 1초 떠 있다가 0.28~0.55초 동안 빠르게 추적 비행합니다. 차체·이름과 겹치지 않게 띄우며 단일 보스 기본 피해 6000·방어력 65% 무시·777 대비 1.5배 크기를 유지합니다. 대기 중 표적 보스가 죽으면 다른 공격 가능한 보스를 다시 찾습니다.
- 협동은 획득한 플레이어의 2슬롯·교체 선택을 사용하고 상대 슬롯을 바꾸지 못합니다. 북 오라는 가까운 협동 아군에도 적용됩니다. 저장·이어하기·AI·웨이브 테스트도 지원합니다. 기존 저장의 힐팩·포격권·전투 강화·특수부대는 보존합니다.
- 보급 2분 주기·120초 유효시간·기본 호위 6명과 접근 증원 4명·호위 생존 중 획득을 유지합니다. 7분대 완화, 미드 보스 30%, 사방 증원, 기존 적·진화·병과 연계 수치는 이번 패치에서 변경하지 않았습니다.
- 검증: 회귀 테스트 278개 통과. 실제 렌더러 8방향 이동·정지·지원 효과, 실제 게임 교체창과 보스킬러 대기·적중을 확인했습니다. 회사 PC 작업 인계는 [docs/SUPPORT_TOYS_HANDOFF.md](docs/SUPPORT_TOYS_HANDOFF.md)를 참고하세요.
