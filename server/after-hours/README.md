# AFTER HOURS — 닫힌 방의 기록

Render 주소: `/after-hours/`. PC 키보드와 마우스로 플레이하는 3D 밀실 방탈출의 첫 번째 장입니다.

## 구조

316호는 침실·거실·간이주방·욕실이 분리된 스위트룸입니다. 침실의 필름, 거실의 액자, 간이주방 식탁의 작업표·탁상시계, 욕실의 잠긴 수납장과 UV 전구, 거실의 스탠드·거울을 오가며 연결해 출입문을 엽니다. 욕실 세탁 안내표에도 빛과 거울에 관한 단서가 있습니다.

거실 출입문 밖은 호텔 3층 복도입니다. 316호에 맡겨진 동행인의 예비 열쇠로 복도 건너편 317호에 들어갑니다. 317호에서는 영수증·수하물표·여행가방·오르골·문양 금고 퍼즐이 이어집니다. 317호 비상문을 열고 나가야 첫 장이 끝납니다.

공간별 경계와 문 통과 조건은 public/room-layout.js를 공유합니다. 자유 탐색은 별도 시작 버튼으로 제공합니다.

## 조작과 표현

- 몸을 낮춰 가구 아래를 관찰하고, 사물을 클릭하거나 E로 집습니다.
- 액자는 실제 3D 관찰 화면에서 드래그로 뒤집습니다. 뒷면이 보일 때만 뒤에 붙은 조각을 가져갈 수 있습니다.
- 필름 조각을 조합하고, 작업표 위에서 직접 드래그·회전해 정렬합니다.
- 시계 바늘, 서랍, 전구, 광원, 커튼, 문 고리를 조작합니다. 서랍과 문은 3D 공간에서 열립니다.
- 특정 빛 아래의 거울은 현재 벽에 없는 기록을 반사합니다. 실제 Reflector 패스 안에서만 기록 레이어를 렌더합니다.
- 자동으로 다음 할 일이나 정답을 제시하지 않습니다. H 도움말은 요청 시 단계별로 공개합니다.

WASD 이동, 마우스 드래그 또는 방향키 시점, E/클릭 조사, C 몸 낮추기, I 인벤토리 열기/닫기, J 관찰 기록, H 도움말, 숫자키 소지품 선택, ESC 닫기/일시정지. 자유 탐색 중 L은 실내 조명, U는 스탠드 조명 미리보기입니다. 진행은 새로고침하면 초기화됩니다.

## 관리자 테스트 시작

`/after-hours/?admin=1`로 열면 공간과 퍼즐 단계를 고르는 관리자 테스트 창이 나옵니다. 침실·거실·간이주방·욕실·호텔 복도·317호·비상구로 바로 이동하거나 시계·수납장·UV 거울·오르골·금고 단계부터 시작할 수 있습니다. 이전 단계의 필수 아이템과 문 잠금 상태가 함께 준비됩니다. 플레이 중에는 F2 또는 상단 관리자 테스트 버튼으로 다시 엽니다.

‘모든 문을 열고 자유롭게 둘러보기’를 켜면 완료 화면 없이 이동할 수 있습니다. 자동 이어가기는 이 브라우저의 localStorage에 2초마다 테스트 위치·진행·시계 바늘을 저장합니다. 수동 저장·불러오기·지우기도 가능합니다. 자동 이어가기를 끄면 매번 시작 위치 선택 창이 열립니다. 일반 URL에서는 이 저장을 읽거나 관리자 버튼을 표시하지 않습니다. 관리자 테스트는 클라이언트 플레이 도구이며 서버 관리 권한은 제공하지 않습니다.

특정 지점 공유: `/after-hours/?admin=1&start=bath` 또는 `/after-hours/?admin=1&start=room317&free=1`. 명시한 시작 지점이 저장된 진행보다 우선합니다. 저장된 진행에서 계속하려면 `start` 없이 관리자 URL로 접속합니다.

검증: `node --test server/after-hours/test-starts.test.mjs`.

## 그래픽

욕실·주방·거실·침실 가구와 원형 벽시계는 Blender 4.4에서 만든 별도 GLB 모델입니다. `art/build_fixtures.py`가 원본이며 외부 메시 없이 미터 단위로 생성합니다. 세면볼·싱크볼은 실제 상판 개구부와 안쪽 벽을 갖고, 변기에도 빈 볼과 별도 시트·덮개가 있습니다. 수납장 양문, 샤워부스 문, 욕실 문, 옷장 양문, 여행 가방 뚜껑, 벽시계 바늘은 분리된 노드입니다. 침실 가방은 짐 받침대로 옮겨 옷장 앞 통로를 확보했습니다.

`domestic-models.js`는 모델 로딩, 움직이는 노드와 충돌 영역, 반사 거울, 금속 표면의 환경 반사를 연결합니다. 로딩에 실패하면 기존 가구와 퍼즐 조작이 유지됩니다. 모델별 정적 부품은 부모·재질 단위로 합쳐 렌더링 호출 수를 줄였습니다.

모델 재생성: `blender --background --python server/after-hours/art/build_fixtures.py -- --out work/fixture-build`

Poly Haven CC0 벽지·헤링본 바닥·직물의 컬러/노멀/거칠기 맵, imagegen으로 생성한 호텔 사진, 직접 모델링한 가구와 전화기·탁상시계·스탠드·가방·문 장치, 실제 평면 반사, 그림자, 창밖 빗줄기와 실내 먼지를 사용합니다. `public/credits.txt`에 출처·라이선스·사진 프롬프트를 기록했습니다.

317호의 화장대·의자·침대 옆 협탁·램프·여행가방·금고·오르골과 316호 냉장고·식탁·의자·서비스 카트는 `art/build_room_details.py`로 생성합니다. 가방 안감과 옷, 금고 내부·볼트, 오르골 실린더·빗살·기어를 실제 메시로 만들고 힌지를 분리했습니다. `room-details.js`는 퍼즐 숫자·문양, 애니메이션, 가구 충돌과 317호 평면 거울을 연결합니다. 세 거울은 서로를 숨기는 반사 가드를 공유해 재귀 렌더를 막습니다. 욕실 타월은 봉을 감싼 천 메시이며, 주방 주전자도 곡면으로 다시 만들었습니다.

모델 재생성: `blender --background --python server/after-hours/art/build_room_details.py -- --out work/room-details-build`.
욕실·주방만 재생성: `blender --background --python server/after-hours/art/build_fixtures.py -- --out work/fixture-build --only Bathroom316 Kitchen316`.
