렉시오 비공식 온라인 플레이판

구현: 이 저장소에서 새로 작성한 규칙 엔진, 서버, UI와 SVG 문양입니다.
일반 타일 배경은 공식 화이트판 자료를 참고해 이미지 생성 도구로 만든 뒤 사용자가 승인한 그림입니다.
구름은 검정, 별은 주황, 달은 초록, 해는 빨강이며 숫자 2는 별도의 전체 면 문양으로 표시합니다.
일반 숫자는 빈 원 안에 선명한 SVG 텍스트로 표시하며, 숫자 2는 사용자가 제공한 원본 PNG의 문양별 영역을 그대로 표시합니다.
배경과 숫자 2 이미지의 상세 출처: assets/ARTWORK.md
3~5인, 컴퓨터/친구와 플레이, 1·2·3·5개 족보, 자동 점수 정산을 지원합니다.
오리지널 기본 규칙을 사용하며 특수카드 확장은 포함하지 않습니다.
