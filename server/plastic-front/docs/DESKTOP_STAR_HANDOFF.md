# 책상 전초기지 · 2성 인수인계

- 시작 화면 → 전장 선택에 새 2성 맵을 추가했습니다. 2,800 × 3,200의 책상, 푸른 작전 매트, 중앙 기지, 네 방향 통로와 책·키보드·문구류를 새로 배치했습니다. 기존 책상 디펜스와 별도로 선택합니다.
- 같은 병과 1성 3기 → 2성 1기 자동 합성. 기존 2성 공격력 3배·체력 및 치료량 2.5배, 레토나 독립 룰렛 3개와 병과별 최대 2성 3기를 적용합니다.
- 중앙 기지 체력 4,000, 기관총 포탑 2개와 완성 바리케이드 2개로 출발합니다. 시작 자원 135는 차감하지 않으며, 기본 건물도 건설 한도에 포함됩니다. 멀티탭 엄폐 6곳과 기존 책상 건설 한도 2배를 활용해 20분간 기지를 지키면 승리합니다. 기지 파괴 또는 대장 후퇴 기회 소진 시 패배합니다.
- 일반 증원·비행 적·돌격대·보스는 화면 밖 사방에서 접근합니다. 아군 근처 및 장애물 위 생성을 피하고, 막힌 방향은 다른 진입로를 찾습니다. 분대가 400 이내에서 적을 가로막으면 적이 분대와 먼저 교전하며, 분대가 떠나 기지가 노출되면 기지를 공격합니다.
- 첫 일반 무리는 8초, 돌격대는 3분 30초, 첫 보스는 4분부터 등장합니다. 이후 보스는 기본 2분 간격이며 기존 보스 생존 및 처치 후 대기 규칙을 따릅니다. 중장갑 일반 벌레의 합류 시점을 늦춰 초반 합성 시간을 주고, 6분 이후 공세 규모를 늘렸습니다.
- 시작 화면 미리보기·맵 안내·미니맵·저장 이름·이어하기·AI 및 백그라운드 계산을 연결했습니다. AI는 중앙 기지를 기준으로 사방 요격 위치를 고릅니다. 웨이브 테스트는 기존 거실용이며 이번 맵에는 추가하지 않았습니다.
- 검증: 게임·협동·보드게임 서버 테스트 476개 통과. 새 맵 11개 검사에서 합성·배율·화면 밖 사방 생성·통로·보급 접근·저장 복원·기지 보호·20분 승패를 확인했고 실제 브라우저에서 선택·출격·이동·지형 표시를 확인했습니다. 난이도는 첫 버전이며 수동 20분 클리어를 검증한 값은 아닙니다.

- public/desktop-star.js: 맵 치수, HQ, 시작 건물/보급/소품, 전용 웨이브 파생 설정, 캔버스 지형. waves-defense.js를 복제하므로 기존 모드 수치를 바꾸지 않습니다.
