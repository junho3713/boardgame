# 방바닥 · 2성 인수인계

- 장난감 공장 맵을 선택 목록에서 제거하고 공장 전용 코드·미리보기·설비를 삭제했습니다. 기존 공장 주소는 방바닥 맵으로 전환됩니다.
- 새 전장은 방바닥입니다. 기존 게임의 입체 생활용품 그림체를 사용해 나무 마루·천 러그·커다란 실내화·방석·책·블록·장난감 수납함을 배치했습니다. 작은 플라스틱 병정이 집 안 생활용품 사이에서 싸우는 크기감으로 맞췄습니다.
- 수납함은 내장 imagegen으로 새 투명 입체 소품을 만들고 게임용 WebP로 내보냈습니다. 추가 소품 약 100KB, 실제 맵에서 만든 선택 미리보기 약 22KB입니다. 기존 실내화·방석·책·블록 이미지를 재사용하며 새 수납함은 해당 맵에서만 불러옵니다.
- 같은 병과 1성 3기 → 2성 자동 합성, 공격력 3배·체력 및 치료량 2.5배, 레토나 독립 룰렛 3개를 적용합니다. 사방 공세·4분 첫 보스·20분 중앙 기지 방어, 기본 포탑 2개·바리케이드 2개와 기존 2성 방어 규칙을 이어갑니다. 러그는 통행 가능하며 책·블록 엄폐 4곳은 인접 아군 방어력 +12입니다.
- 보이는 생활용품과 실제 이동 충돌을 연결하고, 설비 종류에 관계없이 방바닥의 모든 소품이 본게임 렌더러에 표시되도록 연결했습니다. 가려진 병사는 소품의 반투명 표시로 확인할 수 있습니다.
- 기존 공장 저장은 방바닥으로 이어집니다. 경과 시간·자원·별 등급·전사·기지 및 건물 피해는 유지하며, 새 장애물과 겹친 위치만 조정합니다. 기존 거실·책상 저장은 해당 맵을 유지합니다.
- 검증: 게임·협동·보드게임 서버 테스트 489개 통과. 방바닥 전용 13개 검사에서 합성·룰렛·사방 생성·통로·엄폐·승패·저장·공장 저장 이전과 실제 전투 렌더러 연결을 확인했습니다. 실제 브라우저에서 예전 공장 링크의 전환, 방바닥 선택·출격·생활용품 표시·클릭 이동을 확인했습니다. 기본 AI로 첫 3분 기지 유지와 2성 합성도 확인했습니다. 난이도는 첫 버전이며 수동 20분 승률까지 검증한 값은 아닙니다.

## 구현 위치

- public/bedroom-star.js: 맵 데이터, 기존 FrontLivingRoom의 floorSurface/wovenRug/windowLight 및 furniture를 쓰는 방바닥 렌더러, 새 수납함 투명 이미지, 공장 저장 이전.
- world.id=bedroom, variant=bedroom-star, bedroomStar=true. starDefense()/isDesktopDefense()로 기존 2성 방어 규칙을 재사용합니다.
- 모든 소품에는 bedroom:true가 있고 desktop.js의 obstacle/depth/visible/opacity가 FrontBedroom에 연결합니다. kind만 검사하면 slipper/books 등 기존 종류를 가진 소품이 본게임에서 빠지므로 이 연결을 유지하세요. bedroom-star.test.cjs에서 실제 desktop.js를 실행해 검사합니다.
- 기존 실내화는 기존 윤곽 충돌 슬라이스, 나머지는 바닥 몸체 사각형을 사용합니다. 러그·채광·마루 이음매는 장식이며 통행을 막지 않습니다.
- factory-star URL/기기 선택은 bedroom-star로 전환합니다. unpack 직후 upgradeBedroomMap이 옛 공장 저장을 새 생활용품 배치로 옮기며 HP·자원·전사 등은 보존합니다. 공장 전용 JS·SVG·테스트·인수인계 파일은 삭제했습니다.
- 내장 imagegen 제작과 정확한 생성 프롬프트: BEDROOM_ART_PROMPT.md. 실제 전투 증거: 작업 폴더 outputs/bedroom-star-gameplay.jpg.
- desktop-star → bedroom-star → engine 로드 순서. 캐시 버전 20261115-bedroom1. 생활용품 공통 렌더러 livingroom.js도 같은 버전입니다.
- 전체 검사: node --test server/plastic-front/*.test.cjs server/girl-lobby/*.test.cjs (489개). 2성 방어 웨이브는 desktop-star 파생 설정 공유이며 후속 방바닥 전용 밸런스는 별도 복제해서 조정하세요.
