## 확률 기술 반영 · 2026-11-09

- 네 서포토이의 기술을 기본 70%·강화 25%·대박 5%로 추첨합니다. 한 번의 시전에는 한 결과만 나옵니다. 희귀 보급에서 토이 네 종류가 각각 25%로 합류하는 추첨과 별개입니다.
- 미끼 토이는 예시의 갈색 낚시 수달로 교체했습니다. 8방향 걷기·낚싯대 던지기·물고기 미끼를 표현하며, 12초마다 미끼를 던져 착지 후 최대 3초 동안 일반 적 최대 2명의 어그로를 끕니다.
- 미끼 시전의 25%는 상어, 5%는 메갈로돈입니다. 상어는 반경 140에 소유 대장 공격력의 2배, 메갈로돈은 반경 240에 4배의 피해와 넉백을 줍니다. 솟구침·정점·착수 동작과 물보라를 적용했고, 실제 피해는 솟구치는 시점에 한 번 처리합니다.

- 물대포 거북이는 예시의 올리브색 등껍질·투명 물탱크·크림색 대포 외형으로 교체했습니다. 기본 물줄기부터 굵은 물살·거품·물보라를 표현하고 포구에 연결했습니다. 강화 물대포와 큰 파도의 쓰나미도 서로 다른 형태로 표시합니다.

- 마지막 토이는 예시의 갈색 전기 다람쥐 람쥐썬더로 교체했습니다. 큰 말린 꼬리·줄무늬·노란 배터리와 8방향 걷기·전격·두 팔을 든 소환 자세를 적용했습니다. 10초마다 기본 최대 1명, 연쇄 전격 최대 3명, 대박 람쥐 썬더 최대 8명을 각각 1초 기절시킵니다. 대박은 먹구름에서 대상마다 벼락이 떨어집니다.
- 넉백은 벽·맵 경계와 제어 저항을 적용합니다. 인간형·차량·사검 보스는 넉백 면역, 모든 보스는 기절 면역입니다. 피해는 적의 방어력과 무적 상태를 반영하며, 아군에게 피해를 주지 않습니다.

## 적용 범위와 수치

보급 이름은 **희귀 보급**, 합류하는 유닛은 **서포토이**입니다. 기존 일반 보급과 희귀 보급 2분 주기·120초 만료·호위 6+4명·호위 생존 중 획득은 유지합니다. 새 희귀 보상의 400자원·힐팩·강화·포격권·특수부대 추첨을 네 토이로 대체했습니다. 이전 저장의 소모품·강화·특수부대와 명시적 구형 보상은 호환합니다.

|---|---|---|---|

- 중복은 기존 동일 종류 완전 수리. 가득 차면 소유자만 교체/유지를 선택하며 전장을 멈추지 않습니다. 미선택 상태에서 다음 보급은 소멸시키지 않습니다. 협동에서는 새 교체 선택 때 해당 대장에게 5초 보호를 적용합니다.

- 미끼 HP 75, 보스·길목 대장은 면역, 이미 발사된 투사체는 재지정하지 않습니다.
