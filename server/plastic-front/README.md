## 2인 협동 시험판

`/plastic-front/?coop=1`에서 초록 대장이 방을 만들고, 파랑 대장은 6자리 방 코드로 입장합니다. 두 사람이 연결되면 방장이 출격합니다.

- 기존 **2성 거실맵**의 지형·병과·합성 배율·보스 일정을 재사용합니다.
- 일반 적 웨이브 수량은 **평균 1.8배**이며, 정수 나머지를 다음 웨이브로 넘깁니다. 일반 적과 병과별 동시 등장 상한도 1.8배입니다. 고정 수비대·예약 전차·보스 수와 적 체력·공격력은 그대로입니다.
- 두 분대 모두 아군 판정입니다. 초록과 파랑은 렌더링 색·표식이며, 이동·집중 사격·궁극기·편성은 각자 조작합니다.
- 자원·경험치·레벨·강화·해금·후퇴 횟수·2성 합성은 **개인별**입니다. 처치 보상은 마지막 타격을 준 병력의 대장에게, 보급품은 먼저 획득한 대장에게 돌아갑니다. 자동 수입·시간 경험치는 각각 기존 속도로 지급합니다.
- 레벨업 선택 중에도 **전투는 계속**됩니다. 선택이 시작되면 해당 플레이어 분대에 시뮬레이션 시간 기준 **5초 무적**이 적용됩니다. 선택을 오래 열어둬도 무적은 연장되지 않습니다. 긴급 지원 취소로 무적을 반복 획득할 수 없습니다.
- 각자 후퇴 기회 3회이며, 둘 다 소진하면 패배합니다. 한 명이 모두 소진해도 생존한 친구는 계속 싸울 수 있습니다.
- Node 서버가 기존 엔진을 20Hz로 계산합니다. 브라우저는 인증된 HTTP 조작 요청과 압축된 8Hz 상태 조회를 사용하며, 서버 상태를 표시합니다. 추가 패키지는 필요 없습니다.
- 친구가 끊기면 전체 작전을 멈춥니다. 같은 탭을 새로고침하면 sessionStorage의 참가 토큰으로 재접속하고, 두 사람이 다시 연결되면 재개합니다. 시험용 방은 최대 3개이며, 10분간 접속이 없으면 정리합니다.
