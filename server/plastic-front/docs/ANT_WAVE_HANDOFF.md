# 폭탄개미 연계 웨이브 (2026-11-12)

- 거실 3분 이후 일반 개미 편성 가중치를 기존의 2배로 조정했습니다. 첫 2분과 웨이브 주기·인원·동시 등장 상한은 유지합니다.
- 기존 폭탄개미 24초 재사용·싱글 동시 2마리 한도 안에서 폭탄개미 1마리 + 개미 3마리, 5분 이후 예산이 5칸이면 개미 4마리를 묶어 배치합니다.
- 무리 전체가 화면 밖의 같은 안전한 진입 공간에 생성됩니다. 개미는 느린 폭탄개미 주변 반경 70의 대형으로 이동하고 폭탄개미가 죽으면 일반 추격으로 돌아갑니다.
- 무리가 기존 웨이브 슬롯을 사용합니다. 여유가 4칸보다 적으면 단독 폭탄개미 대신 개미를 선택하고 다음 기회를 기다립니다. 별도 생성기나 밀린 무리 누적은 없습니다.
- 일반 자동 표적은 사거리·최소 사거리·시야·사격 경로를 만족하는 폭탄개미를 우선합니다. 점화 중인 폭탄, 주변 개미가 많은 폭탄 순으로 고릅니다. 직접 집중 공격, 저격 마녀/박격포, 박격포 레이저, AI 본진 방어 우선은 유지합니다.
- 폭발의 적 일반 개미 대상 피해만 2배입니다. 아군과 보스가 받는 피해, 방어력, 폭발 반경 125, 자폭 예고 0.9초와 처치·경험치·골드 귀속은 유지합니다.
- 협동의 종류별 등장 한도 확장 과정에서 빠졌던 폭탄개미·투석 딱정벌레의 시작 시간과 재사용 검사를 복구했습니다. 무리 대형과 남은 재사용 시간은 기존 그래프 저장 방식으로 함께 저장됩니다.

## 검증

게임·협동·서버 회귀 테스트 385개 통과. 새 12개 테스트는 무리 생성/화면 밖 위치/예산/상한/재사용, 실제 정기 웨이브, 대형 이동·해제, 사거리·최소 사거리·시야·엄폐·우선 표적, 3·8·12·19·20분 연계 폭발과 보상 중복 방지, 아군/보스 피해 유지, 협동 저장과 파란 플레이어 보상, 실제 자동 사격과 직접 집중 공격을 확인합니다.
