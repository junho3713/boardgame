주소는 `/plastic-front/combat-lab.html`입니다. 메인 메뉴·일시정지·설정에서 새 탭으로 열며 원래 작전·영구 강화 저장을 읽거나 쓰지 않습니다.

- 레토나: 777/보스킬러/지뢰/끈끈이/스프레이/꽝, 진화 여부와 1~3성. 병과 레벨은 5이며 2성 이상은 세 독립 룰렛을 같은 결과로 지정합니다. 보스킬러는 진화와 유효한 보스를 자동 준비합니다. 지뢰를 선택하면 접근 옵션을 켜며 이후 직접 끌 수 있습니다.
- 서포토이: 4종, 기본/25%/5% 확정 또는 실제 추첨, 1~3성. 동일 획득·다른 토이 획득 버튼으로 실제 보급 교체와 유지 보상도 시험합니다. 정지 중에도 편성 유지/교체를 선택할 수 있습니다.
- 진화: 9병과 레벨 5와 해당 진화 조건 강화를 준비하고 8초 사격합니다. 의무관은 부상·중독 아군 3명을 12초 치료·정화합니다.
- 궁극기: 대장/시노/화염방사/화린/시온. 대장 레벨은 최소 10이며 실제 4초 궁극기를 사용합니다.
- 상대: 개미·소총병·일반 전차·곤충/인간/전차 보스, 1~60명, 모아두기/일렬/둘러싸기, 접근 또는 정지. 연습용 100만 체력만 선택적으로 적용하며 방어력·피해·제어 면역·저항을 유지합니다. 고체력을 끄면 해당 레벨 1·시간 0 기준 적 체력입니다. 적은 공격하지 않습니다.
- 재생: 0.25/0.5/1/2배, 일시정지, 0.05초 진행, 8초마다 새 실험 반복. R은 재시작, Space는 정지/재개입니다. 다시 발동하면 새 엔진 인스턴스로 공격·적·통계를 초기화합니다. 의무관 12초 시험은 자동 반복을 끄면 끝까지 볼 수 있습니다.

`public/combat-lab.js`는 FrontGame의 독립 하위 클래스입니다. 본게임의 castLucky, useSupportToy, fireUnitProjectiles, launchMortar, useUltimate, update, 방어력과 실제 탄착을 사용합니다. 미션·웨이브·희귀보급 자동 생성·자동 합성·경제·경험치·자동 룰렛을 이 클래스에서만 막습니다. 유인 경로 판정과 넉백·기절은 원래 규칙을 사용합니다. 실험용 대상 고체력과 적군의 아군 피해 차단을 제외한 전투 수치는 복제하지 않습니다.

`public/combat-lab-ui.js`는 기존 FrontModels, FrontEffects와 impact/projectile/evolution/commander/combat-feedback, FrontSupportToyView, FrontSupplyUI를 함께 사용합니다. 선택한 캐릭터·적·효과 이미지를 준비한 뒤 시전하며 불러오기는 기존 8초 제한을 사용합니다. support-toys-view.js의 prepare(types)는 해당 토이 이미지의 기존 공유 로딩을 기다리는 API만 추가합니다. 본게임의 전투·연출 수치는 변경하지 않습니다.

통계는 실제 HP 감소 합계·피해 호출 적중 횟수·고유 적중/제어 대상·실제 치료량입니다. 광역 한 발이 여러 적을 때리면 피해 횟수가 늘고, 다단 타격은 같은 적에게 여러 번 집계됩니다. 효과가 늦게 도달하면 재생 시계와 함께 수치가 갱신됩니다. 강화·치명타·별 등급·대장 레벨과 적 종류에 따라 결과가 달라지며 장시간 작전 밸런스의 대체 지표는 아닙니다.
