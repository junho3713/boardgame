## 생성 프롬프트

Use case: stylized-concept. Asset type: ONE transparent game environment prop, a household toy storage basket for a miniature plastic army game set on a normal bedroom floor. Primary request: a single squat rectangular soft-sided canvas toy storage bin, muted dusty blue lower fabric, warm ivory folded rim, two small cloth handles. A few recognizable oversized household playthings peek from the open top: three chunky wooden building blocks in muted ochre/red/sage and a small cream teddy bear head; contents stay within the bin silhouette. Style: polished semi-realistic 3D game prop, tangible woven fabric, restrained stitching, rounded edges, realistic ambient occlusion, same visual family as a plush house slipper and a round fabric cushion rendered as game sprites. Camera: orthographic, high overhead near-top-down looking down at about 65 degrees from horizontal, showing the opening and a shallow front face; long side horizontal, no strong left/right perspective. Soft warm light from upper left, subtle contact shadow toward lower right, genuine transparent background. Whole object fully visible with generous transparent margins, centered, isolated. No room/background/floor plane. No people, no soldiers, no weapons, no machinery, no conveyors, no safety stripes, no labels or text, no UI. Do not make flat vector art, line art, pixel art, an icon, or a cartoon factory. Deliver a detailed high-resolution cutout sprite with clean alpha.
