# 관동 카드 리그

1세대 포켓몬을 테마로 만든 비공식 팬 카드게임입니다. 배치·진화·이동·응원과 6라운드 장소 경쟁은 이 프로젝트의 독자 규칙입니다.

포켓몬 이름과 캐릭터 이미지의 권리는 Nintendo / Creatures / GAME FREAK에 있습니다. 캐릭터 그림은 PokéAPI sprites의 official-artwork PNG를 사용합니다.

이미지 출처: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork
대체 스프라이트: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon

게임은 브라우저에서 실행되며, 원정 상태를 현재 브라우저에 자동 저장합니다. 온라인 멀티플레이는 포함하지 않습니다.
