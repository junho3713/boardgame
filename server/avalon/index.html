레지스탕스 아발론

함께 떠날 사람, 믿어도 될까요?

원정 세 번을 성공시키는 선, 그 안에 숨어 있는 악.
역할은 나만 확인하고, 원정대는 모두 함께 결정해요.

5~10인 · 방 코드로 입장 · 빈자리에 컴퓨터 추가 가능

컴퓨터와 먼저 플레이하기

컴퓨터는 기본 전략으로 선택해요. 사람처럼 자유롭게 토론하는 AI는 아니에요.

무료 서버가 처음 켜질 때는 잠시 기다릴 수 있어요. 서버 재시작 시 방은 종료되며, 방은 최대 2시간 유지돼요.

원탁에 함께 앉아요.

방 코드

    원정대 구성·동시 투표·원정 카드 제출마다 새 시간이 주어져요. 토론을 길게 하려면 120초나 180초를 골라요. 시간이 끝나면 미응답 선택만 자동 처리해요.

    역할과 선택 규칙

    멀린·암살자는 항상 포함해요. 나머지는 선·악 인원에 맞춰 충신과 수하로 채워요.

    방장이 시작하면 모두 같은 원탁으로 이동해요.

    5번이면 악 승리

    누가 누구에게 투표했나요? · 원정대 투표 기록
    원정 카드와 진행 기록

      지금 할 일

      1. 대장이 정해진 수만큼 원정대를 골라요.
      2. 전원이 찬성·반대로 비밀 투표해요. 과반수 찬성이 필요해요.
      3. 선발된 사람만 원정 카드를 내요. 선은 성공만, 악은 성공·실패 중 선택해요.

      원정 3회 성공 뒤에도 멀린이 암살되면 악이 이겨요. 누가 제출했는지는 원정 카드에 표시되지 않아요.

      함께 토론해요

      오른쪽 아래 ‘방 채팅’을 열면 참가자끼리 대화할 수 있어요. 같은 공간이나 음성 통화로 이야기해도 좋아요.

      자신의 역할 카드 화면을 다른 사람에게 보여주지 않아요. 말로 주장하거나 거짓말하는 것은 가능해요.
