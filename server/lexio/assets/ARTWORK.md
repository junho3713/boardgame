# Lexio white tile artwork

The four numberless face backgrounds were generated with the built-in image generation tool using the user-provided white-edition reference chart. The user approved these backgrounds and requested SVG numeral overlays. The four regular faces are cloud (black), star (orange), moon (green), and sun (red).

Prompt brief: Faithfully reconstruct the corresponding regular top-row tile face, remove every numeral, preserve the empty upper-left circle and original lower-right suit emblem, use flat white portrait artwork without perspective, and exclude the chart background and logos.

The rank-2 sprite is the original PNG supplied by the user. Its pixels are not recolored or regenerated; each suit is displayed using an SVG viewport into that original sprite. The approved special faces remain separate from the regular numbered backgrounds.
