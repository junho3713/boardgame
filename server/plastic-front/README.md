## 2인 협동 시험판

`/plastic-front/?coop=1`에서 초록 대장이 방을 만들고, 파랑 대장은 6자리 방 코드로 입장합니다. 두 사람이 연결되면 방장이 출격합니다.

- 기존 **2성 거실맵**의 지형·병과·합성 배율·보스 일정을 재사용합니다.
- 일반 적 웨이브 수량은 **평균 1.8배**이며, 정수 나머지를 다음 웨이브로 넘깁니다. 일반 적과 병과별 동시 등장 상한도 1.8배입니다. 고정 수비대·예약 전차·보스 수와 적 체력·공격력은 그대로입니다.
- 두 분대 모두 아군 판정입니다. 초록과 파랑은 렌더링 색·표식이며, 이동·집중 사격·궁극기·편성은 각자 조작합니다.
- 자원·경험치·레벨·강화·해금·후퇴 횟수·2성 합성은 **개인별**입니다. 처치 보상은 마지막 타격을 준 병력의 대장에게, 보급품은 먼저 획득한 대장에게 돌아갑니다. 자동 수입·시간 경험치는 각각 기존 속도로 지급합니다.
- 레벨업 선택 중에도 **전투는 계속**됩니다. 선택이 시작되면 해당 플레이어 분대에 시뮬레이션 시간 기준 **5초 무적**이 적용됩니다. 선택을 오래 열어둬도 무적은 연장되지 않습니다. 긴급 지원 취소로 무적을 반복 획득할 수 없습니다.
- 각자 후퇴 기회 3회이며, 둘 다 소진하면 패배합니다. 한 명이 모두 소진해도 생존한 친구는 계속 싸울 수 있습니다.
- Node 서버가 기존 엔진을 20Hz로 계산합니다. 브라우저는 인증된 HTTP 조작 요청과 압축된 8Hz 상태 조회를 사용하며, 서버 상태를 표시합니다. 추가 패키지는 필요 없습니다.
- 친구가 끊기면 전체 작전을 멈춥니다. 같은 탭을 새로고침하면 sessionStorage의 참가 토큰으로 재접속하고, 두 사람이 다시 연결되면 재개합니다. 시험용 방은 최대 3개이며, 10분간 접속이 없으면 정리합니다.
- 협동 진행은 서버 메모리의 해당 방에만 보관합니다. 서버 재시작·배포 시 방이 종료됩니다. 기존 싱글 저장이나 영구 강화에는 기록하지 않습니다.

주요 구현: `coop-engine.js`(개인 상태·합성·성장·무적), `coop-server.cjs`(방·인증·시뮬레이션), `coop-client.js`(접속·입력·동기화). 적 수 배율은 `CoopGame`의 `coopSpawnScale`로 조정합니다.

검증: `node --test server/plastic-front/*.test.cjs server/girl-lobby/server.test.cjs`


## 의무병·진화 표시·말벌 조정 (2026-11-05)

- 리나 의무병은 입체 명암을 갖춘 새 8방향 모델, 5시점 걷기, 앞/옆/뒤 치유, 피격/쓰러짐 시트를 사용합니다. 전투 능력치는 기존 의무병과 같습니다. 협동 입장 시 각자 기본/리나 스킨을 고릅니다.
- 협동 스냅샷은 병력 객체와 전투 참조를 유지해 걷기 위상이 갱신마다 초기화되지 않도록 합니다.
- 진화 이름은 병력 소유자의 진화 상태로 표시합니다. 슈퍼 럭키 레토나는 룰렛과 겹치지 않도록 차량 아래에 표시하며 1~3성 모두 지원합니다.
- 말벌 보스 내려찍기 직격은 대상 최대 체력의 50%를 실제로 차감합니다. 방어력으로 이 비율이 줄어들지 않습니다. 착지 범위와 독의 기존 지속시간·피해량은 유지합니다. 협동 5초 무적은 직격과 새 독 부여를 모두 막습니다.
- 새 스프라이트는 내장 ImageGen으로 제작했고 알파를 보존했습니다. `tools/pack-rina-v2.py`가 생성 원본을 결정적으로 잘라 등록하며 새 매니페스트/시트를 만듭니다.


## 웨이브 편성·상성 조정 (2026-11-05)

- 개인 거실 웨이브 테스트에 시간대 추천/현재 분대 복사/직접 조절을 추가했습니다. 병과별 1성 투입 수·Lv., 작전 레벨·생산 자원과 능력 5종을 조절합니다. 2·3성 합성, 진화와 최대 체력은 실제 엔진으로 계산하며 편성 한도를 검증합니다.
- 추천 편성은 분당 2레벨과 이전 보스 보상 수를 기준으로 강화 예산을 분배하는 성장 예시입니다. 실제 플레이 기록의 재현이나 승리 보장은 아닙니다. 개인 영구 강화는 그대로 복사하고 테스트 중의 변경은 원래 저장에 반영하지 않습니다.
- 저격병은 시야·사거리·사선 안의 살아 있는 얼음 마녀를 우선합니다. 직접 집중 공격 명령은 유지합니다.
- 이동형 얼음 마녀는 6분 이후 혼합 웨이브를 대체하는 가중치 0.7로 합류합니다. 추가 스포너는 없고 단독 최대 2기(협동 기존 1.8배 상한 규칙 적용), 이동속도 85, 기존 빙결·아이스 실드를 사용합니다. 고정 수비 마녀는 계속 고정·부활 규칙을 사용합니다.
- 장수풍뎅이 보스 돌격 준비 1초, 속도 800(기존 400의 2배), 거리 360으로 조정했습니다. 돌격 뒤 3초 빈틈과 피해 배율은 유지합니다.
